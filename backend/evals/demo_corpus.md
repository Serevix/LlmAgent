# LLM 工程入门演示语料

这份文件由本项目编写，仅用于验证上传、切分、向量化和检索流程。它不参与真实书籍评测。

## RAG

检索增强生成（RAG）先从知识库检索与问题相关的片段，再把片段交给语言模型生成回答。回答应标注来源；找不到可靠依据时应说明证据不足。

## LangGraph

LangGraph 用图组织有状态的流程。节点处理状态，边确定下一步；条件边可以根据状态选择不同路径。Checkpoint 保存图执行状态，使会话能够在后续请求中继续。

## 向量索引

Embedding 模型把文本转换为向量。索引和查询必须使用兼容的 Embedding 模型及维度。Milvus 可以按用户和书籍元数据过滤检索结果。
